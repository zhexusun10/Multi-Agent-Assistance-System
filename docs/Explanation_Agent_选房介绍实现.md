# Explanation Agent V3：逐套房源介绍与选房辅助

当前已升级到3.1：整体位置比较、自然交通措辞、动态叙述与Top5说明见[现行版本](Explanation_Agent_整体比较与Top5.md)。下文保留3.0的设计与验收范围；当前完整提示词附录随源码重新生成。

2026-10-23。本版本将角色从“复述筛选与排序理由”改成“有依据地介绍每套房源的特点、差异和取舍”。需求补充卡片、需求提取、Orchestrator意图规则和Recommendation算法保持原有逻辑。

当前角色契约、完整提示词、Skill及9条few-shot输出见[源码生成的提示词附录](Explanation_Agent_选房介绍_提示词附录.md)。

## 数据如何进入

名单、展示编号、月租等推荐字段、逐项条件状态、分数及原始排序仍来自Recommendation。它们是推荐结果的权威来源，不由Explanation修改。

仅靠当前推荐接口不足以介绍完整配套。因此C在生成前，只针对本轮最多8个已选房源ID，通过现有数据API读取SQL详情和Neo4j周边：

| 信息 | 来源及用法 |
| --- | --- |
| 月租、卧室、挂牌面积、房屋类型 | 优先使用本轮推荐值；补充读取不能覆盖有冲突的推荐值 |
| 卫生间数量、补充面积或类型 | SQL详情记录；可以帮助选择，不代表推荐阶段已验证相应条件 |
| MRT | 图谱NEAR_MRT或SQL挂牌标注；明确是挂牌标注距离 |
| 公交站/公共交通点 | 只有接口实际返回相应类别时才可介绍；没有收录就不编造 |
| 超市、市场、食阁、商场、公园、诊所等 | 图谱NEAR_PLACE中的具名地点和直线距离 |
| 原始排序原因 | 推荐的实际贡献与原生存档；用户明确问排序时才重点解释 |

每套并发读取两个接口，每批两套，最多16次只读请求。不搜索新房，不获取或识别照片，不调用外部路线服务；读取有工具权限、超时、短缓存及执行追踪。规范化资料单独存入当前会话的domain_payloads，正文生成元数据保存enrichment_refs。

补充接口失败时继续使用已有推荐资料，不把失败说成“附近没有设施”。详情ID、目标集合和数据版本不符时拒绝使用；重复补充记录也拒绝。零卧室、零面积不转成真实特点。更换推荐后仍由原有请求/操作关联检查拒绝过期解释。

## 如何找出有用特点

程序为每套整理known_refs、extra_refs、additional_refs、highlight_refs和caution_refs。additional_refs标出用户没提过、但有数据支持的特点；模型正常介绍整组时至少使用其中一项。

月租和挂牌面积可以在本轮已知值之间做精确比较，生成可追溯的差值。例如某套比另一套每月少300新币，或者挂牌面积多200平方英尺。它们是供用户权衡的事实，不是额外评分或重新排序，也不自动推断用户的新偏好。未知面积不参与比较；不笼统保证最低价、最大、性价比最高。

每套选2至3个侧重点，不强行把所有房子说得同样好：有的月租较低，有的挂牌面积较大，有的附近有具名MRT或采购地点。有重要必须条件未确认或资料冲突时，在这套的介绍中简短说明；未提到的可选字段缺失，不逐项报缺。

## 生成与校验

角色契约、system prompt、应用Skill和few-shot均已更新为新任务。9条模板覆盖逐套比较、低价与面积取舍、卫浴数量、混合资料、学校/超市取舍、实际排序问题、英文、空结果和浏览线索，每次选择2条。正文仍由LLM生成。

默认表达为：一句“以下信息可能帮助您更好地比较这几套房子：” → 按原展示顺序逐套介绍 → 一次简短提醒。每套约60至130中文字。用户只问某套或明确比较时，限定回答目标。

公开JSON协议保留version=2.0，新增可空listing_id用于绑定每个房源正文块，最多10块容纳8套及开场/结尾；角色及生成元数据版本为3.0。前端继续显示summary，无需新增工程信息或改变卡片布局，既有历史消息也不重写。

校验分为两层：

- 本地Zod/程序检查：字段、长度、目标覆盖、每套一个正文块、原顺序、标题编号、引用存在性、引用实体归属、补充信息覆盖、必须条件未知/冲突引用、数值和精确标识、禁止内部日志与未经核实的路线便利承诺。
- 独立LLM复核：核对段落真正表达的事实、数字归属、比较方向、有用补充、生活意义是否越界，以及把“低价是选择亮点”误说成“低价导致排名”等语义错误。不能仅因出现低价优势就拒绝，因为新角色允许介绍未参与排序的特点。

仍保留最多3次尝试和90秒生成阶段总时限。程序校验不能完全代替语义审查，不宣称模型永不出错。仅查询资料不会增加模型调用；生成与独立复核沿用已有生产链路。

## 对生活意义的限制

“具名超市直线约200米，日常采购多一个选择”是允许的有限说明；“去该超市步行3分钟”没有路线证据，不允许。MRT记录可以作为公共交通选择参考，不能保证通勤方便、班次丰富或四通八达。

卫生间数量不等于独立使用权，挂牌面积不等于单独卧室面积，公寓类型不证明有泳池/健身房/家具。不能根据照片补这些设施，不能承诺可租、预约或实际入住人数。
