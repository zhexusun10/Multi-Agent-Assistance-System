# 牛车水、荷兰村：地点匹配与解释失败排查

## 实际故障记录

根据本机已保存的业务操作、Requirement提案和C任务错误定位，而非仅凭截图推测：

1. “帮我找牛车水附近的房子，预算3000新币每月，卧室数量1间”进入Requirement。地点目录只有规划区、站点和原OSM设施集，没有这两个街区节点；牛车水中文别名也没有对应街区，因而返回地点未找到。
2. 用户解释“牛车水就是新加坡的china town”后，模型输出`name=Chinatown, explicit_station=false`，语义本身没有要求地铁站。LocationService却在无规划区匹配时查找同名站点，并默认用车站出口作街区参考，实际落成`LTA:MRT:CHINATOWN`。这不是用户要求MRT，也不是模型在这一轮凭空提MRT。
3. “那改为：帮我找荷兰村附近的房子”输出了荷兰村location，但`removals=[]`；语义审计还错误地放行。增量合并按目标ID区分条件，因此Chinatown旧条件与新Holland Village条件同时保留。荷兰村也被上述解析逻辑替换成同名LTA站。
4. 原生Recommendation目前读取普通OSM `Place`点位，不读取应用的LTA出口实体，所以这两个错误的LTA目标都没有实际距离；不能进行用户本想要的街区就近比较。推荐B任务本身完成，界面中已有房源，最后失败的是C解释任务。
5. 两次C错误不同：第一轮语义复核混淆了比较事实的归属，且把“成立/可保留/非硬性错误”的意见也放进了拒绝列表；第二轮确定性校验报“未补充用户没问的信息”。原实现只把extra_refs中的某个副本算作补充信息，未把同一已知面积的原始引用或由其导出的比较算进去，存在误拒绝路径。

## 修改

- 新增独立、可重放的OSM街区目录，核对[Chinatown节点](https://www.openstreetmap.org/node/2511049756)与[Holland Village节点](https://www.openstreetmap.org/node/8777049478)。坐标来自OSM，不由LLM生成；保留对象ID、版本、源更新时间、获取时间、来源和ODbL许可。中文、英文及China Town空格变体映射同一街区。
- 地点解析不再将未指定类型的街区默认替换为站点；唯一的模糊设施结果也不能直接冒充目标。明确要求MRT时仍按独立LTA站点解析。
- 距离采用OSM街区标注参考点的直线距离，既不是街区边界距离，也不是车站出口或实际步行路线。新增Place节点及327条采样半径内关系；使用原生已有距离与评分逻辑，不修改Recommendation算法。
- Requirement系统提示词、语义审计及Skill增加“替换地点”和“追加地点”的区分；补充短句few-shot。“那改为B附近”须删除旧具名找房地点的对应条件，保留未修改的预算、卧室和泛指配套偏好。继续由LLM理解增删改，没有增加关键词规则接管语义。
- Explanation的补充信息按语义字段和引用来源闭包判断。原始面积及其有效比较可以作为用户未要求的额外信息；重复的单位换算副本不是唯一合法引用。错误数字、其他房源的独占事实和重要未知状态仍受校验。
- 比较事实明确写双方房名、各自数值和差值，并带`subject_listing_id`，去掉容易让复核器误解的“本套”主语；复核提示词只允许真实错误进入issues，不把可选改进当失败。

## 验证与费用边界

- 构建通过；Node本地测试274条通过、22条环境测试跳过、0失败。
- 两个街区分别经过真实本地Recommendation调用验证，取出的4套均有已知距离，顺序按距离递增；另外独立用SQL房源坐标和街区点重新计算，误差小于1米。
- 荷兰村案例前4套的距离约为599、733、1038、1194米；牛车水案例约为368、573、1284、1284米。缺坐标的其他房源继续保持未知。
- 短句替换经过严格Schema、真实LocationService解析、合并及本地模型桩验证；本次没有声称已完成真实LLM需求生成与语义审计的全流程验收。
- 真实模型请求总数限定3次：首个验收脚本继承外层终端旧凭证，返回401；只读核对确认与项目`.env`不同后，改用项目标准`with-project-env.mjs`。余下2次用于同一个荷兰村案例的Explanation生成及独立复核，两者一次通过、没有纠错重试。未运行批量付费回归。
- 报告：`evaluation/reports/neighbourhood-local.json`和`evaluation/reports/neighbourhood-live.json`。脚本默认不调用模型，付费模式有持久化次数上限及防重复执行保护。
